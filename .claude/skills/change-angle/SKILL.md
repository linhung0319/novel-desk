# 換一種方式再答

作者已經看過你的回答，覺得不夠。這次要走不同的路，不是把剛才的話換句話說。

作者補充：$ARGUMENTS

## 怎麼做

不是在問寫作方法的需求（查資料、算時間、找章節），就直接處理，不讀索引和招卡。

1. **看卡成什麼樣子。**

   | 狀況 | 要做的事 |
   |---|---|
   | 沒東西 | 用 `books/<書名>/raw/` 或現有設定做組合、連問 |
   | 太套路 | 對現有答案做變換 |
   | 選不下 | 針對這本書，說明各方向會鎖死什麼 |

2. **選招。** 讀 `knowledge/索引.md`，先定領域再看症狀，選 1–2 招。作者點名招式時，直接讀那張卡。

3. **讀卡。** 只讀 `knowledge/cards/<招名>.md` 裡選定的卡，不要多讀。

4. **看這本書。** 只讀回答需要的部分。

5. **回答。** 開頭說用了哪招，接著照卡片的 `吐` 給候選。

## 沒有合適的招

勉強對得上就算沒有。直接說沒有合適的招，再照自己的想法換個方向回答。

只有「選不下」的情況，就算沒有招，也要說明各方向會鎖死什麼。

## 回答的規矩

- **用這本書的東西：** 候選要指得出這本書的人、事、句子。放到別本書也通的就不算。
- **卡片是材料：** 不必照步驟跑完，挑對這裡有用的。例子只示範形狀，不要搬進候選。
- **不表態：** 不說「我會選」「最好」「比較容易」，不排名，不替作者決定。作者問了才說。
- **候選要真的不同：** 走不同的路，不是同一個想法的三種講法。給之前先對照你剛才的回答，已經講過的點子不要再當候選，換個說法也一樣。
- **不落檔：** 不評分、不填表、不寫檔。作者說「記下來」才寫，寫之前先給他看。
- **短：** 給完候選就停。不要前言，不要總結，不要提議接下來還能做什麼。

作者可以說「換一招」，就換另一招重答；也可以要你列出所有對得上的招，就只列招名和一句話，不要全部展開。
