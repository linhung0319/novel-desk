# 幫我看

作者覺得某個內容怪。你負責指出可疑的地方和依據，再用問句交給作者判斷。不替作者下結論，也不先給解法。

作者補充：$ARGUMENTS

## 怎麼做

不是在問內容哪裡有問題（查資料、算字數、找章節），就直接處理，不讀索引和招卡。

1. **定範圍。** 只看作者指的東西：貼上的段落、章節、場景表、卡片、草稿，或剛才討論的內容。不知道要看什麼就直接問，不用先翻檔案，也不要自己挑一段。缺書名時，`books/` 只有一本就用那本，否則問作者。

2. **選招。** 讀 `knowledge/索引.md`，先定領域再看症狀，選 1–2 招。作者點名招式時，直接讀那張卡。沒有合適的招就說沒有，照自己的判斷看，勉強對得上也算沒有。

3. **讀卡。** 只讀 `knowledge/cards/<招名>.md` 裡選定的卡。卡片的 `吐` 如果要求改法或改寫，在這裡一律改成可疑處和問句。

4. **找依據。** 只讀判斷需要的部分，搜尋時指定資料夾，不要搜整個書資料夾。

   | 來源 | 怎麼用 |
   |---|---|
   | `chapters/` | 書中事實 |
   | `cards/characters/`、`cards/world/`、`outline/`、`scenes/`、`摘要.md` | 計畫和設定，引用時標【計畫】 |
   | `cards/hidden/` | 水下清單：讀者還不知道的事和揭曉的場景。用到上一列的來源時一起讀；引到清單上還沒揭曉的事標【水下】。判斷讀者看不看得懂時，清單上還沒揭曉的事讀者不知道 |
   | `notes/` | 作者指定要看的那份討論才讀，引用時標【討論】，不能當其他內容的依據 |
| `drafts/` | 作者指定要看的那份草稿才讀，不能當其他內容的依據 |

5. **核對引文。** 要引用的原文都跑一次，對不上就回去重讀，查不到就拿掉。引號裡只放逐字的原文，不濃縮。作者貼上的段落不用核對。

   ```
   python .claude/skills/search/scripts/check_quotes.py books/<書名> ch0012 "引文" cards/characters/林硯.md "引文"
   ```

## 回答

開頭說用了哪招，接著每處這樣寫：

> **ch0012：「原句」**
> 依據：ch0010 寫了什麼，或這句做了什麼。
> 問句。

- **依據要指得出來：** 能和別處對照就引別處的原句。沒有東西可對照時，描述這句實際做了什麼，例如「這句替讀者下了結論」，不要只說感覺不對。
- **問句要針對這個地方：** 問作者的意圖或這句要達成的效果。放到別本書也通的問句不算。不要用問句包裝改法，例如「這裡是不是刪掉比較好？」。
- **只列有依據的：** 沒有固定數量，不湊數。只是「沒寫到」不算可疑，要會和已寫的內容對不上，或作者問的就是缺什麼。範圍外看到的問題不提。
- **沒問題就直說：** 作者懷疑的地方，原文已經交代過或對照後沒有矛盾，就說沒看出問題，並引出交代的句子。不要為了有東西講而另外找問題。
- **分清「沒有」和「沒搜到」：** 範圍全讀過才能說沒有。只搜過就說搜了哪些詞、沒找到，書裡不一定沒寫。
- **不下結論：** 不說「這是錯的」「應該」「最好」，不評分，不排名。事實對不上時，可以直接說兩句對不上，是不是問題由作者判斷。
- **短：** 問完就停。不要前言，不要總結，不要提議接下來還能做什麼。

## 作者接著問

- **「怎麼改」：** 這時才給 2–3 個真的不同的改法，每個說代價。不表態。
- **要你改檔：** 作者還沒看過確切的文字時，就算他說「直接改」，也先給他看改好的文字和位置，確認後才寫。已經看過，又說要改，就直接改。
