# 落筆

作者要寫一章。你負責組 prompt、送出、整理各稿，不替作者寫，也不替作者選。

作者補充：$ARGUMENTS

## 1. 組 prompt

**範圍：** 章號補成四位數，下面的 `chNNNN` 都指這一章。缺書名、章號或本章事件時，問作者，不要自己編事件。

**可以讀：**

- 本章對應的 `beats/`、`outline/`
- `摘要.md`
- 本章出場角色的 `cards/characters/`，和本章用得到的 `cards/world/`
- `chapters/` 裡的前文

**不可以讀：**

- `cards/hidden/`：沒揭露的真相不能進 prompt。
- `drafts/`：沒採用的劇情不算事實。
- `samples/`：除非作者要求加範文。

照 [templates/prompt.md](templates/prompt.md) 寫到 `books/<書名>/drafts/chNNNN/prompt.md`。

**組的時候：**

- **不寫任何行文指令。** 像「緊湊」「張力」「動詞有力」「刪贅字」「少用形容詞」「展示不要講述」都不放。寫法段只有鏡頭和篇幅。
- **事件只寫發生什麼。** 不寫這場的意義、情緒重心、人物心裡在想什麼。
- **對白只寫意圖，** 不寫可以直接貼上的句子。
- **角色只放會出場的，** 寫他會做什麼、在意什麼，不貼標籤。卡片沒寫的不要補，這一章用不到的可以省。
- **前情講發生過的事和怎麼發生的，** 用完整的句子，不轉述人物的心情，也不下評語。只放這章要接得上的，長度看來源有多少，不要湊字數，也不要重複上一章結尾已經有的內容。
- **上一章結尾放最後，** 原文照貼，不修改。沒有前文就刪掉這段。

## 2. 給作者過目

把 `prompt.md` 全文貼給作者看，然後附上這幾點，每點幾行就好，沒有就省略：

- **可能洩漏：** 提醒作者檢查卡片和事件裡有沒有讀者還不該知道的事。你讀不到水下，這點只有作者判斷得了。
- **你補的東西：** 來源檔案沒寫、你自己補上的細節。
- **來源對不上：** 卡片、前文、幕綱互相矛盾的地方。照來源寫，不要自己解決。
- **會被照演的行為句：** 卡片上有特定習慣的句子幾乎每一稿都會照演，例如一進門就看門窗。列出來，留或刪由作者決定，不要自己刪。
- **可選的意義句：** 如果這章的重心是人物關係，作者可以自己加一句。它會讓稿子更有重心，但常被直接說出來，要在挑句時刪。不要自己加。

等作者說可以送才往下。作者要改就照改。

## 3. 送出

```
python .claude/skills/draft/scripts/send.py books/<書名> chNNNN <稿數>
```

稿數預設 3，作者可以要 3–5。腳本在空資料夾、無工具、無設定的環境生成，稿件寫到 `drafts/chNNNN/稿1.md`、`稿2.md`……已有的稿不會被覆蓋，再跑一次就是加稿，編號接下去。

**不要改用 subagent 或自己動筆。** 那樣會帶進這個對話和專案的 context。

腳本回報 `水下比對` 有命中時，把命中的句子告訴作者，由作者決定留不留。作者自己寫進事件的真相是可以的。

## 4. 整理各稿

親自讀完每一稿，再回報。回報只有這幾段：

**重複的梗。** 同一處情節，兩稿以上用了同樣的處理或措辭，而這不是 prompt 要求的。列出梗、幾稿有、各引一句原文。重複最多的排前面。這是模型的預設反應，作者只看一稿時會以為是靈感。

**只有一稿有的。** 只有這一稿想到的處理或句子，標稿號，引原文。只列新東西，不列措辭不同但意思一樣的。

**走樣。** 違反 prompt 的地方，例如該保密的揭露了、事件漏了或改了、人物做了卡片和前文對不上的事。也列稿子自己補上、之後會變成事實的新設定。沒有就寫「沒有」。

不排名，不評分，不說哪一稿最好，也不說哪句好。作者問了才說。

**產生並排檔：**

```
python .claude/skills/draft/scripts/compare.py books/<書名> chNNNN --mark <梗的原文片段> <片段> ...
```

`--mark` 放重複的梗在稿子裡的原文，會以底色標出。腳本產生 `drafts/chNNNN/並排.html`，把路徑告訴作者。

## 5. 拼接定稿

作者說要用哪幾句、哪幾段時才做。

- **照抄作者選的文字，** 不順手潤飾。
- **接縫由你補時，** 只補銜接必要的字，並列給作者看。
- **寫入前先給作者看全文，** 作者確認後才寫 `chapters/chNNNN.md`。檔案開頭依 README 寫 `摘要` 和 `POV`。摘要也要作者確認。
- **不要新寫段落。** 作者要你重寫某段時，先問是要改 prompt 再生幾稿，還是由你直接改。
