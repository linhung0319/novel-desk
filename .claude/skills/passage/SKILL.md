# 局部操作

作者選了一段，要你對它做一件事。你負責給候選，不替作者選，也不改檔。

你看不到作者之前的對話。這是刻意的，那段對話可能看過還沒揭露的真相。作者的交代只有下面這行：

作者補充：$ARGUMENTS

## 1. 定段落

作者會貼上段落，或給章號加起訖句。

作者貼上段落又沒給章號時，到 `chapters/` 搜它的句子。找到就照章號處理，找不到就當成還沒進書的段落。

下面這些情況，用「你」直接告訴作者缺什麼就停，不要猜，也不要自己挑一段：

- 沒有段落，或沒說要做什麼。
- 起訖句在那一章找不到，或不只一處。
- 作者提到「剛才」「照我們說的」。你看不到那段對話，請作者把要點寫進指令。
- 缺書名，而 `books/` 不只一本。只有一本就用那本。

## 2. 讀

**可以讀：**

- 段落所在的那一章。段落在章首時，再讀上一章結尾。
- 段落裡和你要寫到的角色的 `cards/characters/`，和用得到的 `cards/world/`。
- 提下一步時，再讀對應的 `scenes/`、`outline/`、`摘要.md`。

**不可以讀：**

- `cards/hidden/`：沒揭露的真相。
- `drafts/`：沒採用的劇情不算事實。
- `notes/`：討論區，還沒定的想法不算事實。
- 這一章之後的章節：可能有這段還不該知道的事。
- `samples/`：除非作者要求。
- `knowledge/`：除非作者點名招卡，那就只讀 `knowledge/cards/<招名>.md` 那一張。

列檔和搜尋都只指定上面可以讀的資料夾，不要列整個書資料夾，也不要列 `cards/`。卡片記了這段之後才發生的事時，不要提前寫出來。

## 3. 做

| 作者要 | 做什麼 |
|---|---|
| 擴寫 | 保留原有的事件和順序，把段落寫長 |
| 補感官 | 原句盡量留著，插入看、聽、聞、摸、嚐得到的東西 |
| 改對白 | 只動對白和對白旁的動作，敘述不動。作者給了意圖就照意圖 |
| 提下一步 | 給三個方向，各用兩三句寫發生什麼，再一句寫它會鎖死什麼。不寫正文 |
| 其他 | 照作者說的做 |

改文字預設給 3 版，作者指定幾版就給幾版。各版差在處理方式，例如不同的細節或重心，不是只換措辭。

作者沒要求動的句子逐字照抄，不順手換詞、不調語氣，也不刪你覺得多餘的句子。要加的東西加進去，原有的事件、用詞和順序留著。

各版要接得上前文的人稱和語氣，和段落的前後句接得起來。POV 角色不知道的事不要寫進去。

## 回答

只有這些，沒有就省略：

```
位置：ch0012「起句」到「訖句」

### 版本 1
可以直接替換的全文

### 版本 2
……

新增的事實：每一版補上、之後會變成事實的新東西，標版本。包括 POV 角色的過去。
對不上：段落和前文或卡片矛盾的地方，引原句。照原文寫，不要自己解決。
```

段落還沒進書時，位置寫「貼上的段落」。提下一步時，把「版本」換成「方向」。

不排名，不評分，不說哪一版好。不要前言和總結，也不要提議接下來還能做什麼。
