# 搜尋

作者要查這本書寫過什麼。先定範圍，再找，核對引文後才回答。不下評語，不提建議。

作者補充：$ARGUMENTS

## 1. 定範圍

缺書名時，`books/` 只有一本就用那本，否則問作者。問題裡的「他」從對話判斷，判斷不了就問。

**章節：** 章號補成四位數，對應 `chapters/chNNNN.md`。

| 作者說 | 範圍 |
|---|---|
| 第 3 章、第三章 | 只有 `ch0003` |
| 第 10 到 20 章、前三章 | 那幾章 |
| 最近五章 | 現有章號最大的五章 |
| 截至第 20 章、第 20 章時 | `ch0001`–`ch0020`。答案和證據都不能用後面的章，也不要提後面發生什麼 |
| 沒說 | 全部 |

**來源：**

| 來源 | 什麼時候查 | 回答時 |
|---|---|---|
| `chapters/` | 一律先查 | 這才算書中事實 |
| `cards/characters/`、`cards/world/`、`outline/`、`beats/`、`摘要.md` | 作者問設定或計畫，或正文查不到時 | 標【計畫】，不能說成已經發生 |
| `cards/hidden/` | **只有作者明說要查水下** | 標【水下】 |
| `notes/` | **只有作者問到討論過什麼** | 標【討論】，不能說成已經發生或已經決定 |
| `drafts/` | 永遠不算 | 不查，不引用 |

搜尋時指定上面的資料夾，不要搜整個書資料夾，否則會搜進 `cards/hidden/`、`notes/` 和 `drafts/`。

指定了章節範圍時，每次搜尋都用 glob 限定在範圍內，例如截至第 72 章用 `ch00[0-6]*.md` 和 `ch007[0-2].md` 各搜一次。看過範圍外的內容就會影響判斷，也可能寫進給 subagent 的說明。

## 2. 找

**範圍在 3 章以內：** 直接讀，不搜。

**範圍更大：** 先搜再讀命中的章。一次搜不夠：

- 同一件事用多組詞搜，包括同義詞、別名、具體動作和物件。查「受傷」也要搜傷、血、疼、包紮。
- 別名在 `cards/` 開頭。POV 角色在第一人稱章節裡是「我」，搜名字會漏，改搜他做的事。
- 沒字可搜時，搜 `chapters/` 的 `^摘要:` 看全部摘要，定位後再讀章。摘要只用來定位，不能當證據。

**要全讀的情況：** 作者要求、問題要盤點（哪些伏筆沒收、某人做過的所有事），或要回答某事「有沒有」且範圍不超過 20 章。

**讀超過 3 章時交給 subagent，** 每批約 10 章，同時開。每個 subagent 要知道：只讀指定的檔案，不讀 `cards/hidden/`、`notes/` 和 `drafts/`；回報相關內容的章號和逐字原句，沒有就說沒有。

## 3. 核對引文

每句要給作者的原文都跑一次，subagent 回報的也一樣：

```
python .claude/skills/search/scripts/check_quotes.py books/<書名> ch0012 "引文" outline/總綱.md "引文"
```

引文要是能看出意思的完整句子，不能只有幾個字。對不上的句子不能當原文引用，回去重讀，查不到就拿掉。

## 4. 回答

```
答案，一兩句。

- ch0012：「原句」
- ch0035：「原句」

查了：全讀 ch0030–ch0040；沒查水下。
```

- **每個事實都要有原句，** 但只引撐得起答案的句子，通常一到三句。原文沒明說、由你推出來的，標「推論」。
- **問題的前提不對就直說，** 例如原文根本沒寫他受傷。
- **分清「沒有」和「沒搜到」，第一句就要分清。** 範圍全讀過才能說「沒有」。只搜過就說「在哪個範圍搜了哪些詞，沒找到」，並說明書裡不一定沒寫，不要先斷言沒有、最後才補一句。例外：問的是某個字詞有沒有出現時，搜遍範圍就夠了，可以直接說沒有。
- **截至第 N 章時，計畫也不能透露後面。** 卡片和大綱裡寫到之後才發生的內容不要引用。
- **`查了` 一定要寫：** 全讀了哪些章，或搜了哪些詞；有查計畫或水下也要寫。
- **盤點類的答案是候選清單，** 開頭要說明，由作者判斷。
- **水下的內容不要帶進之後的落筆或局部操作。** 回答完提醒作者：這個對話已經看過水下，寫稿要開新對話。
