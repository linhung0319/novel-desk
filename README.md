# novel-desk

人主導、AI 輔助的小說寫作工具。這份文件是存放慣例。

## 一本書的資料夾

```
books/<書名>/
├── raw/                    # 隨手丟素材，沒有格式
├── 摘要.md                 # 一頁：主線、題旨、結局、基調
├── cards/
│   ├── characters/<名>.md
│   ├── world/<主題>.md     # 道具、地點也放這裡
│   └── hidden/<名>.md      # 水下：還沒揭露、AI 提前知道就可能寫壞的真相
├── outline/                # 總綱.md、arc01.md…
├── scenes/arc01.md         # 場景表：一個故事弧拆成的場景
├── samples/                # 範文：作者挑的人類片段
├── drafts/ch0001/          # 落筆的 prompt 和各稿，不算書的內容
├── chapters/ch0001.md      # 正文定稿
└── notes/                  # 討論區：討論過程、還沒定的想法、決定和被否決的理由
```

資料夾名固定用英文；檔名可以用中文，書名、角色名和主題照作者的叫法。資料夾用到時再建，不必一開始建齊。

## 用詞

| 中文 | English | 是什麼 | 寫成的文件 |
|---|---|---|---|
| 故事弧 | story arc | 一段大目標，從立起來到收掉。由場景組成 | 大綱（outline）：`outline/arc01.md`；全書的叫總綱，`outline/總綱.md` |
| 場景 | scene | 局勢改變一次：場景的開頭和結尾，處境不同。由節拍組成 | 場景表：`scenes/arc01.md`，一個故事弧一檔 |
| 節拍 | beat | 角色碰壁後換一次做法（McKee 的定義）。同一種來回重複幾次，仍是同一個節拍 | 不另存，`/draft` 排章時產生 |
| 章 | chapter | 正文的切分。由一到多個場景組成，有一個主要高點。場景可以跨章 | 正文：`chapters/ch0001.md` |

左欄是敘事裡的一段，右欄是寫它的文件：說「這個故事弧」講的是故事，說「這份大綱」講的是文件。

故事弧之間、場景之間決定起伏；節拍決定快慢，以及高點有沒有被讀者感覺到。

## 討論區和正式區

`notes/` 是討論區，一個題目一檔，格式自由。`cards/`、`outline/`、`scenes/`、`chapters/` 是正式區，只放定案的內容。兩邊不同步：討論區記過程，正式區才算決定，討論區舊了也不用回頭改。

討論區不算書中事實，和 `drafts/` 一樣。

## 固定格式

只有下面兩處有固定格式，其他自由書寫，沒有 lint。

卡片開頭：

```yaml
---
別名: [塔主, 白袖先生]
---
```

章節開頭：

```yaml
---
摘要: 林澈發現墨斑洗不掉，被老抄寫員瞥見。
POV: 林澈
---
```

## 為了好搜

- 一章一檔，檔名帶章號。
- 卡片寫別名，每章寫一句摘要。
- 搜不到關鍵字時，先從摘要定位，再讀章。
- 查書中事實時只算 `chapters/`。`drafts/` 有沒採用的劇情，不能當作事實。

## 開一本新書

每本書用獨立 git，要有自己的備份，測試用的書也一樣。`books/` 被工具的 git 忽略，不用 submodule。

```
mkdir books/<書名>
cd books/<書名>
git init
```
