# 場景注意事項

`/settle` 寫場景表前讀。這些是每次都該成立的條件，不是寫作技巧；卡住想找方法時用招卡。作者看過說照寫，就照寫。

逐個場景看下面五題，只回報有問題的，標出場景名。五題是你要看的東西，不要原樣貼給作者。每一項照這個順序寫：

- 先說你在場景表上看到什麼：這一場寫了什麼，引原句。
- 再說缺了什麼，或哪裡接不上。
- 作者在對話裡說過理由的，把理由寫出來。
- 最後才問作者，給得出選項就給。

例如：「上車去城南：這一場只寫了一行人上車往城南開，和小戰士偷瞄陸辛的畫面。從開頭到結尾沒有誰的處境變了，前一場也沒有哪件事導致這一場。你說過想寫那個畫面。要留成獨立的場景，還是併進下一場當開頭？」

寫出看到什麼之後，發現答案其實已經在場景表或前面的場景裡，這一項就不報。


1. 開頭和結尾，處境哪裡不同？說不出來的可能只是過場：可以併進旁邊的場景，或寫成正文時一句帶過。
2. 誰想要什麼？被什麼擋著？
3. 和前一個場景之間，接得上「所以」或「但是」嗎？只接得上「然後」的，可以換結果、換順序，或併掉。
4. 整個故事弧有高有低嗎？指得出最高的那個場景嗎？它前面有沒有場景在墊，還是一路平著上去？場景表有標章號時，也看每一章：這一章最高的是哪個場景？整章都在墊、沒有高點的，列出來。
5. 沒交代的事，是刻意留給讀者猜的懸疑，還是只是沒寫到？刻意的在場景表註明；不是的，寫成正文時直接交代。

不檢查文筆、節拍和篇幅。
